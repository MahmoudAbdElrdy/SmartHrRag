# مقارنة llama3.2:3b و qwen2.5:3b على نفس البحث

المقارنة دي بتغيّر موديل الإجابة فقط. الـ embeddings، والسياسات، والمقاطع المسترجعة، والـ prompt، ودرجة الحرارة ثابتين. أي فرق في النص راجع للموديل مش للبحث.

التاريخ: 12 نوفمبر 2026. التشغيل من واجهة Angular على `http://localhost:4200/ask`، والـ API على `http://localhost:5080`.

## إيه اللي ما اتغيرش

- Embeddings: `bge-m3`
- نفس السياسات المتخزنة في SQL Server
- `TopK = 3` (الافتراضي في `SearchRequest`)
- `temperature = 0` داخل `OllamaClient.AnswerAsync`
- نفس `PromptBuilder`: الإجابة من المقاطع فقط، ذكر `[Source N]`، ولو المعلومة غير موجودة يقول ذلك، وبنفس لغة السؤال

التبديل من غير تعديل `appsettings.json`:

~~~powershell
docker compose exec ollama ollama pull qwen2.5:3b
$env:Ollama__ChatModel = "qwen2.5:3b"
dotnet run --project src/SmartHr.Api --urls http://localhost:5080
~~~

للرجوع إلى Llama:

~~~powershell
$env:Ollama__ChatModel = "llama3.2:3b"
~~~

جزء التوليد في `src/SmartHr.Infrastructure/OllamaClient.cs`:

~~~csharp
model = config.ChatModel,
prompt,
stream = false,
options = new { temperature = 0 },
~~~

## الأسئلة

الملف `tools/compare-models/questions.json` فيه الثمانية أسئلة والإجابة المتوقعة. فيهم عربي فصحى، وعامي مصري، وإنجليزي، وسؤال إجازة الوضع غير موجود في المستندات عمدًا.

تصوير الإجابات من الواجهة:

~~~powershell
cd tools/compare-models
npm.cmd install
node shoot.js llama3.2_3b
# غيّر Ollama__ChatModel وأعد تشغيل الـ API، ثم:
node shoot.js qwen2.5_3b
~~~

السكريبت يفتح Chrome على `/ask`، يكتب السؤال، وينتظر الإجابة، ويحفظ لقطة وصورة البطاقة و`answers.json`.

## النتيجة

المقاطع المسترجعة كانت نفسها للسؤال الواحد، بنفس الترتيب ونفس نسبة التشابه. أول سؤال لكل موديل أبطأ لأن الموديل كان بيتحمّل. المتوسط تحت محسوب على الأسئلة من 2 إلى 8.

| السؤال | llama3.2:3b | qwen2.5:3b |
|---|---|---|
| إجازة سنوية لخبرة 3 سنوات: 21 يوم | صح | صح |
| أجر الإضافي في عطلة الأسبوع: 150% | صح، مع اسم القسم | صح، مع رقم المصدر |
| 20 يوم إجازة مرضية: 15 كامل + 5 بنسبة 75% | الحساب صح، وبعدين جملة زائدة مربكة | غلط: قال إن الخمسة أيام بدون راتب |
| المرتب يوم 27، ولو عطلة في يوم العمل السابق | صح، وصياغة أعم | صح، وذكر التحويل البنكي |
| يومان من البيت بعد فترة التجربة وموافقة المدير | غلط: لم يذكر اليومين | اليومان وفترة التجربة صح، وموافقة المدير ناقصة |
| أقصى هدية من مورّد: 100 ريال | صح، مع المصدر | صح، من غير مصدر في النص |
| ساعات رمضان: 6 | صح، مع المصدرين | صح ومختصرة |
| إجازة وضع، وهي غير موجودة | رفض الإجابة | اخترع يومًا ونسبه لسياسة الإجازة المرضية |
| أسئلة لها مستند (7) | 6/7 | 6/7 |
| السؤال غير الموجود | رفض صحيح | اختراع |
| متوسط الزمن بعد التحميل | 12.5 ث | 8.8 ث |

## القراءة

على العينة دي مفيش فايز مطلق. Qwen أسرع، وإجابته على سؤال العمل من البيت بالمصري كانت أوضح. Llama التزم أكتر بصيغة المصدر، وحسب خصم الإجازة المرضية صح، ورفض السؤال الذي لا يغطيه أي مستند.

فشل Qwen في سؤال إجازة الوضع أخطر من غلطة Llama في سؤال العمل من البيت: الاثنين شافوا نفس المقاطع، لكن Qwen ألصق قاعدة غير موجودة بمصدر حقيقي. تعليمات البرومبت وحدها لا تمنع موديل 3B من اختراع قاعدة.

العينة ثمانية أسئلة، كل سؤال مرة واحدة، وعلى جهاز واحد. الرقم يصلح للمقارنة داخل المشروع، ومش benchmark عام.
